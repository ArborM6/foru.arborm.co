# foru.arborm.co

Marketing / introduction website for **For You（为你）** — a single-player social app
centered on AI character companionship. Currently being carefully crafted (2027).

Tri-lingual (简体中文 / 繁體中文 / English) single-page site built with
Next.js (App Router) · TypeScript · Tailwind CSS v4 · Framer Motion.

## Run locally

```bash
pnpm install
pnpm dev        # http://localhost:3000
```

## Build

```bash
pnpm build
pnpm start
```

## Notes

- Official brand assets (app icon, wordmark, banner, beian icon) live in `public/`.
- No store links, pricing, or legal pages yet — the product is not released.
  Hero CTAs are intentionally non-link "即将开放 / Coming soon" states.
- Phone screens in the "三大入口" section are stylized design mockups, not product screenshots.
